FAQ

YouTube Link & Embed Generator — Frequently Asked Questions

Why does autoplay not start?

Browsers block videos that autoplay with sound. Tick Start muted together with Autoplay and it will start on every modern browser.

Why does loop add a playlist parameter?

YouTube only loops an embedded video when it is also given a playlist — so the tool adds playlist= with the same video ID. That is the documented way to loop one video.

What does privacy-enhanced mode do?

The embed loads from youtube-nocookie.com, so YouTube does not set tracking cookies until the visitor presses play. It is on by default.

Does the end time work on share links?

No — YouTube supports an end time only in embeds. Share links accept a start time (?t=).

Does this page contact YouTube?

Only to show the video’s thumbnail image, and to play the preview if you click it. Building the links and embed code happens entirely in your browser.
