How It Works

How to Use Password Generator in 3 Steps

1

Pick a type

Password for maximum strength, Passphrase for something you can remember and type on a phone, PIN for number-only codes.

2

Tune it

Set the length or number of words and which characters to use. The meter shows the strength in bits and how long a fast offline attack would take.

3

Copy and save

Copy it straight into your password manager. Need several? Set “How many” in Settings and download them as a .txt. Press New password for another.

FAQ

Password Generator — Frequently Asked Questions

How random are these passwords?

They use crypto.getRandomValues, the browser’s cryptographically secure random generator — the same source password managers use — with rejection sampling so every character is equally likely.

Are passwords saved or sent anywhere?

No. They are created in this tab and never stored — not in cookies, not in local storage, not on a server. Closing the tab forgets them.

Where do the passphrase words come from?

From the EFF long word list: 7,776 common, easy-to-spell words. Each word adds about 12.9 bits, so 5 words ≈ 64 bits and 6 words ≈ 77 bits before the extra number.

How is the crack time estimated?

From the entropy: on average an attacker must try half of all possibilities. The estimate assumes a fast offline attack of 10 billion guesses per second — real websites that rate-limit logins are far slower.

What length should I use?

For accounts in a password manager, 16–20 random characters is plenty. For a master password you have to type, a 6-word passphrase is strong and much easier to remember.
