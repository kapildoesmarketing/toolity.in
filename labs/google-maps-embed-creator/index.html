1

            FAQ
            
Google Maps Embed Creator — Frequently Asked Questions

          

          

            

              Do I need a Google Maps API key?
              
No. The generator uses Google's public maps.google.com/maps?output=embed endpoint, which works without a key or a billing account. It shows the standard map with a marker and the usual zoom and fullscreen controls.

            

            

              Is my address sent anywhere?
              
The code is assembled in your browser. The only request made is the preview iframe itself, which loads the map from Google exactly as it will on your site. Toolity has no server involved.

            

            

              Why is there no address autocomplete?
              
Live suggestions require Google's Places API and a billed key. Type the address as you would search it on Google Maps — the embed uses the same geocoder — or paste coordinates like 19.0760, 72.8777 for an exact pin.

            

            

              What does the responsive option change?
              
Instead of a fixed width/height, the iframe is wrapped in a block that keeps your chosen aspect ratio with CSS aspect-ratio and stretches to the full width of its container, so the map looks right on phones and desktops.

            

            

              Can I embed driving directions?
              
Yes. Switch to Directions and enter a start and destination; the embed shows the route, distance and estimated time, and visitors can open it in Google Maps for turn-by-turn navigation.

            

            

              Will the embed slow down my page?
              
The snippet includes loading="lazy", so the browser only fetches the map when it scrolls near the viewport, and referrerpolicy is set the way Google recommends.
