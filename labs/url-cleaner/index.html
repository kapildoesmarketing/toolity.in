            How It Works
            
How to Use URL Cleaner in 3 Steps

          

          

            

              
1

              
Paste your links

              
One URL per line. Bare domains like example.com/page?x=1 are fine — https:// is assumed.

            

            

              
2

              
Pick what to strip

              
Known trackers (utm_*, fbclid, gclid, mc_cid, igshid, ref…) go by default. Open Settings to also drop fragments, force HTTPS or remove every parameter.

            

            

              
3

              
Copy or download

              
The clean list updates live. Copy it, download a .txt, or press Open to visit the first link.

            

          

        


        
        

          

            FAQ
            
URL Cleaner — Frequently Asked Questions

          

          

            

              Which parameters count as tracking?
              
Everything in the utm_* family plus fbclid, gclid, dclid, gbraid, wbraid, msclkid, mc_cid, mc_eid, igshid, yclid, twclid, ttclid, _hsenc, _hsmi, hsCtaTracking, oly_anon_id, oly_enc_id, vero_id, s_cid, mkt_tok, ref, ref_src, spm and si (YouTube share). Add your own under “Also remove”.

            

            

              Will it break links that need a parameter?
              
Functional parameters (ids, page numbers, search queries) are kept unless you tick “Remove all query parameters”. Removed names are listed under the output so you can double-check.

            

            

              Does it unshorten bit.ly links?
              
No — that needs a network request. Use the Redirect Checker for that, then clean the final URL here.

            

            

              Can I paste text that contains links?
              
Each line is treated as one URL. Lines that are not URLs are left as they are and marked “skipped” in the badge, so a mixed paste survives.

            

            

              Is my input sent anywhere?
              
No. Everything is computed by JavaScript in your browser tab. Nothing is uploaded, logged or stored by Toolity.
