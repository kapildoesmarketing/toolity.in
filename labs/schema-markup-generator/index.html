            How It Works
            
How to Use Schema Markup Generator in 3 Steps

          

          

            

              
1

              
Choose the type

              
Article for posts, Product for shop pages, FAQ and How-to for help content, Event, Local Business, Recipe, Video, Job posting, Breadcrumbs, Website (adds the sitelinks search box), Organization or Person. The form changes to the fields that type needs; required ones are marked.

            

            

              
2

              
Fill it in

              
Repeatable sections (FAQ questions, How-to steps, breadcrumb items) have Add / remove buttons. Dates use the picker (ISO 8601 comes out), prices and ratings are checked for range, URLs must be absolute. Warnings appear above the code as you type.

            

            

              
3

              
Paste and test

              
Copy the <script type="application/ld+json"> block into your page’s <head> (or before </body>), publish, then test the live URL in Google’s Rich Results Test. One block per entity — repeat for other types on the same page.

            

          

        


        
        

          

            FAQ
            
Schema Markup Generator — Frequently Asked Questions

          

          

            

              Which types can show rich results in Google?
              
Article, Product, FAQ, How-to, Event, Local Business, Recipe, Video, Job posting and Breadcrumbs are all documented Google rich-result types (eligibility rules change — FAQ rich results, for example, are now limited to authoritative government and health sites). Organization, Person and Website feed the Knowledge Panel and sitelinks search box rather than a visible snippet.

            

            

              Do I need every field?
              
Only the ones marked required — those are what Google lists as required for the rich result. Recommended fields raise the chance of a richer display; leave the rest blank and they are simply omitted from the output.

            

            

              Where exactly does the code go?
              
Anywhere in the HTML, but <head> is conventional. JSON-LD does not need to wrap visible content, unlike Microdata, which is why Google recommends it. If your CMS has a “custom head code” field, paste it there.

            

            

              Can I combine several types in one script?
              
Yes — put them in a JSON array or an @graph. This tool outputs one entity at a time to keep the form manageable; generate each, then combine. Reference one from another with the @id option (e.g. an Article’s publisher pointing at your Organization).

            

            

              Why does my FAQ schema not show up?
              
Since 2023 Google shows FAQ rich results only for well-known authoritative sites, and How-to results only on desktop. Valid markup is still useful for other search engines and AI assistants, but do not expect the dropdown in Google for a typical site.

            

            

              Is my input sent anywhere?
              
No. Everything is computed by JavaScript in your browser tab. Nothing is uploaded, logged or stored by Toolity.
