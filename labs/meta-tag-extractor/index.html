            FAQ
            
Meta Tag Extractor — Frequently Asked Questions

          

          

            

              What length limits do the warnings use?
              
Title: 60 characters (Google typically truncates around 50–60). Description: 160 characters. These are guidance, not hard rules — a slightly longer tag is not an error.

            

            

              Does it see tags added by JavaScript?
              
No. It reads the HTML as served, which is also what most crawlers see first. If your framework injects meta tags client-side, they will not appear here — a good hint that they may not appear for search engines either.

            

            

              Why is the canonical URL different from the one I entered?
              
The page declares it. Relative canonicals are resolved against the final URL after redirects, so a redirecting address will show the destination’s canonical.

            

            

              Can I extract tags from a local HTML file?
              
Yes — open the file in a text editor, copy it all, and paste into the HTML box. Nothing leaves your browser in that mode.

            

            

              Why does fetching sometimes fail — and what is the relay?
              
Browsers block JavaScript from reading other websites directly (CORS). The tool first tries a direct request; when the site forbids it, the URL only is sent to a public read-only relay (allorigins.win, then codetabs.com) that fetches the page and returns its HTML. The relay sees the URL you typed, nothing else — Toolity has no server and keeps no record. If the relay is busy or the site blocks bots, paste the page source instead: that path is 100% local.

            

            

              How do I use paste mode?
              
Open the page in your browser, press Ctrl/⌘+U (view source), select all, copy, and paste into the HTML box. Only the <head> is needed. Paste mode never contacts any server.
