How It Works

How to Use Open Graph Preview in 3 Steps

1

Enter the URL

Type or paste the page address and press Fetch Page. If the site blocks fetching, paste its HTML source into the second box instead.

2

Switch platforms

Facebook, X, LinkedIn and Slack each render the same tags differently — image ratio, title length, where the domain sits. Flip between them to catch truncation.

3

Fix and re-check

Issues (missing image, long title, no description) are flagged under the card; the full og:* / twitter:* table is below. Copy or download the tags as JSON.

FAQ

Open Graph Preview — Frequently Asked Questions

Why doesn’t the preview match what Facebook actually shows?

Facebook, X and LinkedIn cache cards aggressively and apply their own cropping. This tool renders the tags as they are right now; if a platform still shows an old card, use its debugger (Sharing Debugger, Card Validator, Post Inspector) to force a re-scrape.

The og:image is blank — is my tag broken?

Not necessarily. The image is loaded straight from the site; if it blocks hot-linking or is behind a login the preview cannot display it, but the tag itself may be fine. The table shows the exact URL found.

Which tags are used when og:* is missing?

Falls back the same way platforms do: og:title → twitter:title → <title>; og:description → twitter:description → meta description; og:image → twitter:image. X prefers twitter:* when both exist.

Why does fetching sometimes fail — and what is the relay?

Browsers block JavaScript from reading other websites directly (CORS). The tool first tries a direct request; when the site forbids it, the URL only is sent to a public read-only relay (allorigins.win, then codetabs.com) that fetches the page and returns its HTML. The relay sees the URL you typed, nothing else — Toolity has no server and keeps no record. If the relay is busy or the site blocks bots, paste the page source instead: that path is 100% local.

How do I use paste mode?

Open the page in your browser, press Ctrl/⌘+U (view source), select all, copy, and paste into the HTML box. Only the <head> is needed. Paste mode never contacts any server.
