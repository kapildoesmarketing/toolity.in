FAQ

Add to Calendar Link Creator — Frequently Asked Questions

Which calendars are supported?

Google Calendar, Outlook.com, Office 365 and Yahoo Calendar get a direct "add event" link. Apple Calendar, Outlook desktop, Thunderbird and every other app import the standard .ics file the tool generates.

Is my event data stored or sent anywhere?

No. The links and the .ics text are assembled with JavaScript in your browser. Nothing is uploaded to Toolity; the only data transfer happens when you or your recipient open a link to the calendar provider.

How are time zones handled?

Times are interpreted in the time zone shown in Settings (India by default). Google and .ics links carry the zone name so the event lands correctly for guests elsewhere; Outlook and Yahoo links are converted to UTC, which they translate to each user's local time.

Do repeat rules and reminders work everywhere?

Google Calendar and the .ics file support repeat rules (RRULE). Reminders are only part of the .ics file. Outlook, Office 365 and Yahoo links have no public parameter for either, so the event is added once and users set their own alert.

Why is there no "one link for all calendars"?

A single universal link needs a hosted landing page that stores your event on someone's server. Toolity keeps everything client-side, so you get one link per calendar plus an .ics file — paste the ones your audience uses.

Can I put these links in an email?

Yes. Link text such as "Add to Google Calendar" works in any HTML email or web page. For Apple Mail users attach the downloaded .ics file; most mail clients show an "Add to Calendar" button for it.
