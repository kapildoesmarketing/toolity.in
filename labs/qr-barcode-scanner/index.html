How It Works

How to Use QR & Barcode Scanner in 3 Steps

1

Choose a source

Click Start camera (the back camera is preferred on phones — switch cameras or turn on the torch from the row below the preview), or Open file, drop an image, or paste a screenshot straight from the clipboard. Several images can be dropped at once.

2

Read the result

Every code found is listed with its format and content. Links open in a new tab, Wi-Fi codes show the network and password, vCard / MeCard become a downloadable contact, UPI codes show payee and amount, calendar events save as .ics, and phone / SMS / email codes get the right button.

3

Copy or export

Copy any single result, or download the latest as text and the whole session as CSV / JSON. Nothing is stored — reload the page and the list is gone.

FAQ

QR & Barcode Scanner — Frequently Asked Questions

Which codes can it read?

QR Code, Micro QR, Data Matrix, Aztec, PDF417, and the 1D families EAN-13 / EAN-8, UPC-A / UPC-E, Code 128, Code 39, Code 93, Codabar, ITF and DataBar. The browser’s own BarcodeDetector is used when available (Chrome on Android / macOS, Safari); elsewhere the ZXing library is loaded as WebAssembly (about 1 MB, once) and decodes on your device.

Why does the camera not start?

Camera access needs a secure page (https) and your permission — look for the camera icon in the address bar. On iPhone, Safari and Chrome both work; inside some in-app browsers (Instagram, Facebook) the camera API is blocked, so open the page in the real browser. If you have no camera, use a file or paste a screenshot.

The code is in a photo but nothing is found — what helps?

Crop so the code fills more of the frame, make sure it is in focus and not glaring, and keep some light margin around it. Tiny codes in a full-page screenshot can be below the decoder’s minimum size — zoom in and take the screenshot again. Inverted (white-on-black) 1D barcodes are not read.

Is the scanned content safe to open?

The decoder only reads text; nothing runs. Links are shown in full before you open them, and they open in a new tab with noopener. Treat QR codes on posters like any unknown link — check the domain first.

Does anything get uploaded or saved?

No. Frames and images are decoded in your browser and never sent anywhere; results live in the page only until you reload or press Reset. The ZXing fallback is a static file fetched from a CDN, it receives no image data.

Can it read a Wi-Fi or UPI code and connect or pay?

It shows the network name, security type and password (with a copy button) — browsers cannot join Wi-Fi for you. UPI codes show the payee and amount with an Open button that hands the upi:// link to an installed payment app on Android.
