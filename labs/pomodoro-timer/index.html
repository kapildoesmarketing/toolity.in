    How It Works

    How to Use the Pomodoro Timer in 3 Steps

    1

    Pick a task and start

    Add what you are working on, click it to make it current, then press Start (or Space). The ring counts down 25 minutes of focus.

    2

    Take the breaks

    When the chime sounds the timer rolls into a 5-minute break automatically; after four focus sessions you get a longer one. Skip any session with the ⏭ button.

    3

    Review your day

    Each finished focus session is tallied on its task and in today's total. Copy a summary, download the log as CSV, or use Focus mode for a distraction-free full screen.

    FAQ

    Pomodoro Timer — Frequently Asked Questions

    Does the timer keep running if I switch tabs or lock my laptop?

    Yes. The end time is stored as a timestamp, so browser throttling or a sleeping laptop cannot make it drift — when you come back the ring shows the correct remaining time, and if the session already ended you get the chime and notification then.

    Where are my tasks and stats stored?

    In your browser's local storage on this device. Nothing is sent to a server, there is no account, and clearing site data or pressing Reset wipes them.

    Why do I not get desktop notifications?

    Enable them in Settings — your browser will ask for permission the first time. If you previously blocked notifications for toolity.in, re-allow them in the browser's site settings. Notifications also require the page to be open in a tab (it can be in the background).

    Can I change the 25/5/15 lengths?

    Yes. Settings lets you set focus (1–90 min), short break (1–30), long break (1–60) and how many focus sessions come before a long break. Changes apply to the next session.

    What is the Pomodoro Technique?

    A time-management method by Francesco Cirillo: work in focused 25-minute blocks ("pomodoros") separated by 5-minute breaks, with a longer break after four. The short, fixed intervals make starting easier and keep fatigue down.

    Is there a sound file I need to allow?

    No file is loaded — the chime is synthesised with the Web Audio API. Browsers only allow sound after you have interacted with the page, which pressing Start already counts as.
