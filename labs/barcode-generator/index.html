How It Works

How to Use Barcode Generator in 3 Steps

1

Pick a format

Use EAN-13 or UPC-A for retail products, Code 128 for anything else (inventory, shipping, IDs), ITF-14 for cartons.

2

Type the value

Leave the check digit off and it is calculated for you; type it and it is verified. Paste several lines to make a batch.

3

Download

SVG stays sharp at any size for print and design tools. PNG is 4× resolution. A batch downloads as a ZIP with one PNG per line.

FAQ

Barcode Generator — Frequently Asked Questions

Do I need to calculate the check digit?

No. For EAN-13, EAN-8, UPC-A and ITF-14, type the number without its last digit and the check digit is added. If you type the full number, the check digit is verified and a wrong one is reported.

Can I sell products with these EAN codes?

The barcodes are technically correct, but retail EAN/UPC numbers must be licensed from GS1 (GS1 India for Indian products) so they are unique worldwide. Use any number for internal stock.

Which format should I use for inventory?

Code 128: it holds letters, digits and symbols, is compact and every scanner reads it. Code 39 is older and wider but still common in industry.

How are batches made?

Each non-empty line becomes one barcode. The preview shows the first 12; the ZIP contains all of them as PNGs named by line number and value.

Which library draws the barcodes?

JsBarcode (MIT), loaded from a pinned CDN link and run in your browser. Nothing you type is uploaded.
