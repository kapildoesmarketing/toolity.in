            How It Works
            
How to Use Meta Tag Generator in 3 Steps

          

          

            

              
1

              
Fill in what you have

              
Title and description drive everything — the Open Graph and Twitter tags reuse them unless you add a share image. Canonical, site name, author and robots are optional but recommended.

            

            

              
2

              
Check the meters

              
The title and description meters use Google’s real pixel limits (about 600 px and 920 px on desktop). Warnings below the code flag a missing description, an image without alt text, or a canonical that isn’t absolute.

            

            

              
3

              
Copy the block

              
Copy the <head> block or download it as head.html and paste it inside <head>, replacing any existing tags with the same names. Then check the live page with the Meta Tag Extractor and Open Graph Preview.

            

          

        


        
        

          

            FAQ
            
Meta Tag Generator — Frequently Asked Questions

          

          

            

              Which tags does it generate?
              
<title>, description, canonical, robots, author, theme-color, charset and viewport; Open Graph (og:title, og:description, og:type, og:url, og:site_name, og:image, og:image:alt, og:locale) and Twitter Card (twitter:card, twitter:site, twitter:creator, twitter:title, twitter:description, twitter:image). Empty fields are simply left out — no blank tags.

            

            

              Do I need the twitter:title and twitter:description tags?
              
X falls back to the Open Graph tags when they are missing, so strictly no. They are included because other platforms (Slack, Discord, iMessage) and some X previews behave more predictably with both sets present. Set the Twitter card to “None” to leave them out.

            

            

              What is the keywords meta tag — and why isn’t it here?
              
Google has ignored <meta name="keywords"> since 2009 and no major search engine ranks on it. Leaving it out keeps your head clean; nothing is lost.

            

            

              Why the pixel limits instead of character counts?
              
Google truncates by width, not length. The meters measure your text in Google’s font sizes; see the SERP Snippet Preview for the full rendered result on desktop and mobile.

            

            

              Should og:url be the canonical URL?
              
Yes, in almost every case — it tells Facebook and LinkedIn which URL to count shares against, so tracking parameters and duplicates roll up to one page. The default follows the canonical; untick the setting if you need them to differ.

            

            

              Is my input sent anywhere?
              
No. Everything is computed by JavaScript in your browser tab. Nothing is uploaded, logged or stored by Toolity.
