How It Works

How to Use Keyboard Shortcut Cheat-Sheet Maker in 3 Steps

1

List your shortcuts

One per line: Ctrl+Shift+P — Command palette. Start a line with ## to open a group. Chords like Ctrl+K Ctrl+C and alternatives like Ctrl+Y / Ctrl+Shift+Z are understood. Or load a preset and edit it.

2

Pick the look

Write keys Windows-style; the Mac view turns Ctrl/Alt/Shift into ⌘ ⌥ ⇧ automatically (use Control to force ⌃). Choose columns, theme, accent and whether to number rows.

3

Export

Print / PDF opens a clean A4 or Letter page, PNG is pixel-perfect for Slack or a wallpaper, Markdown pastes straight into Notion, GitHub or Obsidian, and HTML is a self-contained file for your wiki.

FAQ

Keyboard Shortcut Cheat-Sheet Maker — Frequently Asked Questions

How are Mac symbols decided?

Ctrl becomes ⌘, Alt becomes ⌥, Shift becomes ⇧ and Win/Super becomes ⌘ — that is how almost every cross-platform app maps its shortcuts. Write Control or Cmd explicitly when you need ⌃ or ⌘ regardless of platform. Arrows, Enter, Backspace, Tab, Esc and Space get their standard glyphs.

Can I show both Mac and Windows keys?

Yes — choose Both and each row shows the Mac combination with the Windows one beside it. Handy for team docs where people use different machines.

What does the Markdown export look like?

A GitHub-flavoured table per group with the keys in backticks, so it renders correctly in Notion, GitHub, Obsidian and most wikis. The Copy button copies the same Markdown.

How do I get a PDF?

Choose Print / save as PDF from the Download menu: a print-ready page opens with your sheet laid out for A4 or Letter; pick “Save as PDF” in the print dialog. Multi-page sheets flow naturally.

Can I save my list?

Your text stays in the box while the tab is open; copy it into a note to keep it. There is no account — nothing is stored on a server.

Is my input sent anywhere?

No. Everything is computed by JavaScript in your browser tab. Nothing is uploaded, logged or stored by Toolity.
