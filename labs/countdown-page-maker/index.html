How It Works

How to Use Countdown Page Maker in 3 Steps

1

Describe the event

Give it a title, a date and time, and — if the audience is spread out — a time zone so everyone counts down to the same instant. Add the message that replaces the clock when it hits zero.

2

Style the page

Pick flip-clock, minimal or compact, dark or light, a font and an accent colour. The preview on the right is the real page, so what you see is what people get.

3

Share it

Copy the link, open it full screen for a projector or lobby display, download the QR code for posters, or send it with the share chips. The .ics file adds the event to Google / Apple / Outlook calendars. Nothing is stored anywhere — the link is the page.

FAQ

Countdown Page Maker — Frequently Asked Questions

Where is the countdown stored?

Nowhere. Every setting is encoded in the link itself, so it works forever, needs no account and cannot expire. The page is served by Toolity’s static site, which has no database — if you lose the link, make a new one in seconds.

How do time zones work?

“Viewer’s local time” means the date you entered is interpreted in each viewer’s own zone (good for “midnight on New Year’s Eve wherever you are”). Pick a specific zone for a single global moment such as a product launch at 9:00 IST — every visitor then sees the same remaining time.

Can I embed it in my website or Notion?

Yes — the same page is the Countdown widget. Paste the link into an iframe, or open the Countdown Widget builder for ready-made embed code with the same settings.

What happens when it reaches zero?

The clock is replaced by your end message (or “Time’s up” if you left it blank). The page keeps working after the date, so a “days since” style page is just a countdown to a past date.

Does the QR code expire?

No — it encodes the link, nothing else. Print it on a poster or invite; it keeps working as long as toolity.in does.

Is my input sent anywhere?

No. Everything is computed by JavaScript in your browser tab. Nothing is uploaded, logged or stored by Toolity.
