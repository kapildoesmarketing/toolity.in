FAQ

Video Format Converter — Frequently Asked Questions

Is my video uploaded to a server?

No. Your browser plays the source file, re-draws each frame on a canvas and records it with the built-in MediaRecorder API. The whole pipeline runs on your device; the file never leaves it.

Why does the output come out as WebM when I picked MP4 or MOV?

The browser decides which codecs it can record. Chrome, Edge and Safari can record H.264 MP4; Firefox can only record WebM. If MP4 isn't available the tool falls back to WebM so you still get a file — the output badge tells you the actual container.

Is a MOV file really different from MP4 here?

Technically MOV and MP4 share the same underlying format (QuickTime/ISO BMFF). The tool records H.264 and names the file .mov, which is what Apple apps expect. If a program rejects it, rename the extension to .mp4.

How long does conversion take?

Recording happens in real time, so a 30-second clip takes about 30 seconds at 1× speed. Trim the clip or choose 1.5×/2× playback speed to shorten the wait. Keep the tab in the foreground — browsers throttle background tabs and may stall the recording.

Is quality preserved?

Not bit-for-bit. The frames are re-encoded at a fixed bitrate chosen for the output resolution, which is fine for sharing but is a second lossy generation. Keep 'Original' resolution and 'Auto' frame rate for the closest match to the source.

What does 'Extract Audio' produce?

An audio-only file (WebM/Opus or M4A depending on the browser) containing the trimmed section's soundtrack, with no video frames. Choose 'Mute Track' instead if you want video without sound.
