FAQ

Image Metadata Remover — Frequently Asked Questions

Is my image uploaded to a server?

No. The file is read with the FileReader API and parsed by JavaScript in your browser tab. Nothing is transmitted, logged or stored anywhere.

What exactly is removed?

EXIF, GPS, XMP, IPTC/Photoshop blocks, comments and PNG text chunks. The ICC colour profile is kept by default so colours do not shift.

Is the cleaning lossless?

Yes — JPEG, PNG and WebP are rewritten at the container level; no pixel is re-encoded (unless you choose to bake in a rotation).

My photo is sideways after cleaning — why?

Cameras often store photos rotated and rely on an EXIF orientation flag. The "bake in rotation" setting (on by default) physically rotates such photos before saving so they stay upright; turn it off only if you want a strictly byte-level strip.

Can I see what will be removed before cleaning?

Yes — the result pane lists everything that was inside, and the Image Metadata Viewer shows the same data without changing the file.
