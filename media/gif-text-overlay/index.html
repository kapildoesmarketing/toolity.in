How It Works

How to Add Text to a GIF in 3 Steps

1

Drop a GIF

Drag an animated GIF onto the left pane. The right pane shows a live preview of the current frame.

2

Write the caption

Type your text in Settings, pick a position, size, colour, outline and font. Use the "Show from / Until" sliders if the text should appear only during part of the animation.

3

Apply and download

Click Apply text. The caption is drawn onto the chosen frames and the GIF is re-encoded with its original timing.

FAQ

GIF Text Overlay — Frequently Asked Questions

Is my GIF uploaded anywhere?

No. The GIF is decoded frame by frame in your browser and re-encoded on your device with a small open-source encoder. Nothing leaves your computer.

Can I add more than one caption?

Apply one caption, download the result and drop it back in for the next — each pass is lossless apart from palette requantisation.

Does the text wrap?

Long captions wrap automatically to fit the width with a small margin. Size is a percentage of the GIF height, so it scales with the image.

Does it keep the original frame timing?

Yes. Each frame's own delay is preserved, so GIFs with mixed timing (a long pause on the last frame, for example) play exactly as before.

Will the quality change?

Frames are re-quantised to a 256-colour palette built from the GIF itself, so the result is visually identical for almost all GIFs. Photographic GIFs with thousands of subtle shades may show slight banding; no dithering is applied to keep files small.
