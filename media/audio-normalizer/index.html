FAQ

Audio Normalizer (LUFS) — Frequently Asked Questions

Is my audio uploaded anywhere?

No. The file is decoded by your browser's Web Audio engine, processed on your device and encoded in the page. Nothing is sent to a server.

What is LUFS?

Loudness Units relative to Full Scale — a measure of how loud audio sounds, not just its peak. It follows ITU-R BS.1770: K-weighting, 400 ms blocks, and gating that ignores silence and quiet passages.

Which target should I use?

−14 LUFS for Spotify, YouTube, Tidal and Amazon; −16 for Apple Music and most podcasts; −23 for EBU broadcast. Streaming platforms turn louder tracks down anyway, so −14 is a safe default.

What does the true-peak ceiling do?

Raising loudness can push peaks above 0 dB, which clips after MP3/AAC encoding. The tool measures inter-sample (4× oversampled) peaks and, if needed, uses less gain so the ceiling is never crossed — the badge then shows the loudest level that fit.

Why is my quiet recording below the target?

This is pure gain with no compression or limiting, so dynamics are kept. When a peak would cross the ceiling, the target cannot be reached without a limiter — set the ceiling to Off only if you accept clipping.

Are mono files measured correctly?

Yes — per BS.1770 a mono channel is weighted 1.0, so a mono file reads about 3 LU quieter than the same audio as dual-mono stereo, matching broadcast meters.
