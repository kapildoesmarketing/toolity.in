FAQ

Video Metadata Remover — Frequently Asked Questions

Is my video uploaded to a server?

No. The file is read with the FileReader API and parsed by JavaScript in your browser tab. Nothing is transmitted, logged or stored anywhere.

What exactly is removed?

User-data and metadata atoms (dates, GPS, device, software, titles, comments, XMP) in MP4/MOV, and Title, DateUTC, Tags, Attachments and track names in WebM/MKV.

Is the cleaning lossless?

Yes — removed atoms are overwritten in place as free space, so chunk offsets stay valid and the video and audio streams are untouched. The file size does not change.

Why is the cleaned file exactly the same size?

Instead of deleting bytes, which would shift every chunk offset and force a full rewrite, the tool renames the metadata atoms to "free" and zeroes their contents. Players skip free atoms, so the metadata is gone while the file stays byte-aligned and valid.

Can I see what will be removed before cleaning?

Yes — the result pane lists everything that was inside, and the Video Metadata Viewer shows the same data without changing the file.
