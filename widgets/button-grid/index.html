How It Works

How to Embed a Button Grid Widget in 3 Steps

1

List the links

One button per line: a label, the URL and an icon name such as lucide:mail — any of the 200k Iconify icons works (simple-icons:github, mdi:home). Up to eight buttons.

2

Shape the grid

Choose 1–4 columns and Soft, Filled or Outline style. Accent, font, corner radius and theme come from the colours panel.

3

Embed

Copy the embed URL and paste it in Notion with /embed, or drop the iframe snippet on any page. Every setting is in the link.

FAQ

Button Grid Widget — Frequently Asked Questions

How do I embed this widget in Notion?

Click Copy in the toolbar to copy the embed URL, open your Notion page, type /embed, paste the link and press Enter. Drag the block handles to fit your column.

Can I use my own icons or logos?

Use any Iconify icon name — brand logos live in the simple-icons set (e.g. simple-icons:notion). Emoji work too: put an emoji instead of an icon name.

Do the buttons open inside Notion?

Links open in a new tab by default so they are not trapped inside the embed frame. Untick “Open links in a new tab” if you embed on your own site and want same-tab navigation.

Where are my settings saved?

Every setting is encoded in the embed URL itself. No account or database is needed, and the link keeps working on any device.

Does the embedded widget track visitors?

No. The /embed/ page loads no analytics or third-party scripts and runs entirely in the visitor's browser.
