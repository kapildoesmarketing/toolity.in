            How It Works
            
Creating URL-Encoded Mailto Links

            
Build pre-populated email links for websites, contact pages, and documentation in 3 simple steps.

          


          

            

              
1

              
Enter Email Parameters

              

                Fill in recipient addresses (To, CC, BCC), email subject line, and draft pre-filled message body template.
              

            


            

              
2

              
Choose Output Format

              

                Select between a raw URL-encoded mailto protocol link, ready-to-paste HTML <a> anchor tag, or Markdown link.
              

            


            

              
3

              
Test Link & Deploy

              

                Click "Test Link" to verify in your default email client (Apple Mail, Outlook, Gmail), then copy the code directly to your website.
