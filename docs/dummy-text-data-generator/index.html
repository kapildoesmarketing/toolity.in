            How It Works
            
How to Use Dummy Text & Data Generator in 3 Steps

          

          

            

              
1

              
Pick a generator

              
Text gives placeholder copy by paragraphs, sentences or words in five flavours — classic lorem, hipster, corporate, tech or real-English pangrams — as plain text, HTML or Markdown. People makes fake contacts (international or Indian names, phones, PIN codes). Dataset lets you define columns and types for any mock table.

            

            

              
2

              
Shape it

              
Tick the people fields you need, or add dataset columns: names, emails, cities, dates, integers and floats with a range, booleans, UUIDs, prices, colours, IPs, or a pick-list (a|b|c). Set a seed in Settings and the same inputs produce the same rows every time — ideal for tests and fixtures.

            

            

              
3

              
Export

              
Copy the result, or download as text, CSV, JSON or SQL INSERT statements. Emails always use reserved domains (example.com, .test, .invalid) so nothing you generate can reach a real inbox.

            

          

        


        
        

          

            FAQ
            
Dummy Text & Data Generator — Frequently Asked Questions

          

          

            

              Is the data really random?
              
It comes from a small seeded pseudo-random generator (mulberry32). With an empty seed a fresh one is drawn each time you reset; with a seed of your own the output is fully reproducible — same seed, same counts, same rows, on any device. Nothing is pulled from the internet.

            

            

              Can generated emails or phone numbers belong to real people?
              
Names are combined from short lists, so coincidences with real names are possible, but emails use only the reserved domains example.com / .org / .net, .test and .invalid, which can never deliver mail. Phone numbers follow the right shape (+91 9xxxx xxxxx, +1 (xxx) xxx-xxxx) but are not checked against any directory.

            

            

              What are the lorem flavours for?
              
Classic lorem is unreadable on purpose, so designers see layout not content. Hipster, corporate and tech read like real sentences in a recognisable register when a mock-up needs believable copy, and pangrams contain every letter of the alphabet — useful for testing fonts.

            

            

              How big can a dataset be?
              
Up to 10,000 rows and any number of columns; the preview shows the first 50 rows and the downloads contain everything. Larger sets are better produced in a script — the browser tab would hold it all in memory.

            

            

              What does the SQL export look like?
              
One multi-row INSERT INTO table (columns) VALUES (…), (…); per 500 rows, with strings single-quoted and escaped, numbers and booleans bare, and empty values as NULL. Set the table name in Settings; it defaults to people or data.

            

            

              Is my text uploaded anywhere?
              
No. Everything runs in JavaScript inside your browser tab. Your text and files are never sent to Toolity or anyone else.
