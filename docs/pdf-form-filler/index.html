How It Works

How to Use PDF Form Filler in 3 Steps

1

Drop a Fillable PDF

Every form field becomes an input on the left, in page order, with its label. If the PDF has no fields the tool says so — scanned forms need a different approach.

2

Fill in the Fields

Type, tick and pick. Values are kept in memory only; nothing is sent anywhere.

3

Save & Download

Click Fill & Save. With Flatten on (default) the values become part of the page — safe to send, impossible to tamper with. Turn it off to keep the form editable.

FAQ

PDF Form Filler — Frequently Asked Questions

The PDF opens but no fields appear — why?

It has no AcroForm fields: it is a scanned or printed form. Fields must exist in the file to be filled here. Use Sign PDF to place typed text onto it instead.

What does Flatten do?

It draws each field's current value onto the page and removes the interactive widget, so every viewer shows the same thing and nothing can be changed afterwards. Leave it off if the recipient must edit the form.

Why does a dropdown show fewer options than in Acrobat?

Only the options stored in the PDF are shown. Some forms compute options with JavaScript, which browsers (and this tool) do not run.

Are signature fields supported?

Not here — digital signature fields need a certificate. For a visible drawn or typed signature, use Sign PDF after filling.

The tool says my PDF is encrypted — what now?

Password-protected PDFs must be opened with their password before they can be edited. Run them through Unlock PDF first, then come back.
