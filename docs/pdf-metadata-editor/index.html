How It Works

How to Use PDF Metadata Editor in 3 Steps

1

Drop a PDF

The form fills with whatever the file currently stores — title, author, subject, keywords, creator, producer and both dates.

2

Edit or Clear

Change any field, or press Clear all fields to blank everything (handy before sharing). Dates use your local time zone.

3

Save & Download

Click Save Metadata. Page content is untouched; only the document information dictionary (and the XMP block, if the option is on) changes.

FAQ

PDF Metadata Editor — Frequently Asked Questions

My viewer still shows the old title — why?

Some viewers prefer the XMP metadata stream over the classic Info dictionary. Leave "Remove the XMP metadata stream" on so the new values win; the file's pages and text are unaffected.

Does this change the file content or quality?

No. Only the document information is rewritten; pages, fonts and images are saved exactly as they were.

Can I remove metadata completely?

Press Clear all fields and save. For a one-click wipe (including XMP) use PDF Metadata Remover, which does exactly that.

Which date format is used?

You pick dates with the browser's native picker in your local time zone; they are stored in the PDF's standard D:YYYYMMDDHHmmSS form with the time-zone offset.

The tool says my PDF is encrypted — what now?

Password-protected PDFs must be opened with their password before they can be edited. Run them through Unlock PDF first, then come back.
