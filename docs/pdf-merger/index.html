    How It Works

    How to Merge PDFs in 3 Steps

    1

    Drop Your PDFs

    Drag several PDFs onto the drop zone at once, or add them one by one. Each file shows its page count and size.

    2

    Put Them in Order

    Use the ↑ ↓ buttons to arrange the files top-to-bottom — that is the order they will appear in the merged document. Remove any file with ✕.

    3

    Merge & Download

    Click Merge. The first page of the combined PDF is previewed, the total page count and size are shown, and the download is one click away.

    FAQ

    PDF Merger — Frequently Asked Questions

    Is there a limit on how many PDFs I can merge?

    No fixed count — the limit is memory. Each file can be up to 100 MB; a few hundred megabytes in total is fine on a laptop, keep it under ~100 MB on a phone.

    Does the merged PDF keep links, forms and bookmarks?

    Page content, links inside pages and form fields are kept. Document-level bookmarks (the outline) are not carried over — add them again in a PDF editor if you need them.

    Can I merge password-protected PDFs?

    Not directly — the tool will name the file that is encrypted. Run it through Unlock PDF first (you need its password), then merge.

    Will page sizes be changed?

    No. Pages are copied as-is, so a merged file can mix A4, Letter and landscape pages exactly like the originals.

    Is my PDF uploaded anywhere?

    No. The document is parsed and rewritten by pdf-lib and rendered by PDF.js (the engine Firefox uses) entirely inside your browser. Nothing is transmitted or stored.
