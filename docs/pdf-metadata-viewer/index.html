FAQ

PDF Metadata Viewer — Frequently Asked Questions

Is my PDF uploaded to a server?

No. The file is read with the FileReader API and parsed by JavaScript in your browser tab. Nothing is transmitted, logged or stored anywhere.

What kind of metadata does the viewer show?

Document Info (title, author, subject, keywords, creator application, producer, creation and modification dates, custom keys) and the XMP packet (Dublin Core, edit history, document IDs), plus page count, page size, PDF version, encryption, forms and attachments.

Why does it matter?

Metadata travels with the file. A photo can reveal where your home is, a PDF can reveal who wrote it and with what, an audio export can reveal the software and account used. Knowing what is inside lets you decide what to share — the PDF Metadata Remover strips it in one step.

Does this remove my name from the PDF text or watermark?

No. This tool only removes hidden metadata. Anything visible on the page — a name in the footer, a watermark, form field values — needs the Redact PDF tool.

The tool says the PDF is encrypted.

Password-protected PDFs must be opened first. Run them through Unlock PDF, then come back.

Can it also remove the metadata?
