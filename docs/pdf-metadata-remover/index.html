FAQ

PDF Metadata Remover — Frequently Asked Questions

Is my PDF uploaded to a server?

No. The file is read with the FileReader API and parsed by JavaScript in your browser tab. Nothing is transmitted, logged or stored anywhere.

What exactly is removed?

Every Document Info entry, the XMP metadata stream and app-private PieceInfo blobs. Pages, fonts, images, links, bookmarks, forms and attachments are left exactly as they were.

Is the cleaning lossless?

Yes — the document is re-serialised by pdf-lib without touching page content streams or images.

Does this remove my name from the PDF text or watermark?

No. This tool only removes hidden metadata. Anything visible on the page — a name in the footer, a watermark, form field values — needs the Redact PDF tool.

The tool says the PDF is encrypted.

Password-protected PDFs must be opened first. Run them through Unlock PDF, then come back.

Can I see what will be removed before cleaning?

Yes — the result pane lists everything that was inside, and the PDF Metadata Viewer shows the same data without changing the file.
