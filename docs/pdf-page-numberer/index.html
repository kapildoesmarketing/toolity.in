How It Works

How to Use PDF Page Numberer in 3 Steps

1

Drop a PDF

The first page renders as a preview. Numbers are added on top of the existing content, so headers and footers stay as they are.

2

Choose Position & Format

Open Settings to pick a corner or centre, a format such as "Page 1 of 12", the first number, how many cover pages to skip, and the size, margin and colour.

3

Add & Download

Click Add Numbers. The preview jumps to the first numbered page; Download the PDF or Open it in a new tab to check every page.

FAQ

PDF Page Numberer — Frequently Asked Questions

Does "skip first pages" change the count?

Skipped pages get no number and are not counted: with 2 skipped and Start at 1, page 3 of the file shows "1". If you want the cover counted but unnumbered, set Start at to 3.

What does Bottom outside mean?

For duplex printing: odd pages get the number bottom-right and even pages bottom-left, so it always sits on the outer edge of the open book.

Will the numbers cover existing footers?

They are drawn on top at the margin you choose. If a footer already sits there, raise the margin or switch to a top position — the preview updates as soon as you run it again.

Can I use Roman numerals or a different font?

Not yet — Arabic numerals in Helvetica keep every viewer happy and the file small. Roman numerals and bold are on the list.

The tool says my PDF is encrypted — what now?

Password-protected PDFs must be opened with their password before they can be edited. Run them through Unlock PDF first, then come back.
