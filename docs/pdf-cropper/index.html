How It Works

How to Use PDF Cropper in 3 Steps

1

Drop a PDF

The first page renders with a crop box over it. Use ‹ › to move to another page; the box keeps its relative position.

2

Draw the Crop

Drag the box or its corners. Auto-detect margins in Settings snaps the box to the content on the current page — ideal for scans with wide white borders.

3

Apply & Download

Choose All pages, This page or a Range, then click Crop. The page's crop box is set — nothing is re-rendered, so text stays sharp and selectable.

FAQ

PDF Cropper — Frequently Asked Questions

Is cropping lossless?

Yes. The tool sets each page's /CropBox, which tells viewers and printers what to show. Content outside stays in the file (hidden); quality and text are untouched.

Can I permanently delete what is outside the box?

Not with a lossless crop. If you need the hidden area gone (for privacy), crop here and then run PDF Flattener in Everything mode, which re-renders only the visible region.

The pages have different sizes — what does All pages do?

The box is stored as a fraction of the page, so a 10 % margin trim applies proportionally to every page regardless of size or orientation.

Why is the box clamped?

A crop box must stay inside the page and be at least 20 pt wide and tall; the handles stop there so you cannot produce an empty page.

The tool says my PDF is encrypted — what now?

Password-protected PDFs must be opened with their password before they can be edited. Run them through Unlock PDF first, then come back.
