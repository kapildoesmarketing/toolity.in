Frequently Asked Questions

Why do I need a multi-resolution .ico file instead of just a PNG?

A standard .ico binary encapsulates multiple resolutions (16×16, 32×32, and 48×48) within a single file. When Windows or browser address bars render the icon, the operating system selects the exact pixel dimension required without blurry browser-side scaling.

Are my uploaded images or logos uploaded to any server?

No. Toolity processes 100% of images locally in your browser memory using the HTML5 Canvas API and JavaScript TypedArrays. Your source files, logo artwork, and generated favicons never leave your device.

Where should I place the generated favicon files in my website?

Extract the downloaded ZIP package and place all image files in your website's root directory (or an /assets/favicons/ directory). Then paste the generated <link> tags into the <head> of your HTML files.
