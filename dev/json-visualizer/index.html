How It Works

Using JSON Visualizer

Paste or Upload JSON

Paste your API response, config file, or raw JSON payload on the left, or upload a .json file from your device.

2

Explore Tree & Table

Click node chevrons to collapse or expand hierarchies, filter keys with instant search, and switch to Table view for tabular datasets.

FAQ

JSON Visualizer & Formatter — Frequently Asked Questions

Is my JSON uploaded anywhere?

No. Parsing, formatting, tree rendering and CSV export all run in JavaScript inside your browser. API responses with tokens or personal data never leave your machine, and the page works offline once loaded.

What does Auto-Repair fix?

Common copy-paste damage: single-quoted strings, unquoted keys, trailing commas, comments and smart quotes. It is a best-effort heuristic — always check the result, and it can't recover truncated JSON.

How do I copy the path to a value?

Hover any node in the Tree view and click the path icon. It copies a JavaScript-style path such as data.items[2].price that you can paste straight into code or a debugger.

How large a file can I visualize?

Formatting handles tens of megabytes. The Tree view renders nodes lazily, but expanding everything in a file with hundreds of thousands of nodes will be slow — switch Default Tree Expansion to 'Collapsed' for very large payloads.

How does the CSV export work?

The Table view flattens an array of objects into rows, one column per key (nested objects become dotted column names). Export CSV writes exactly what you see in the table, so filter or pick the right array first.

Why are my keys in a different order?

Key Ordering defaults to 'Natural' (the order in your input). Choose 'A→Z' to sort keys alphabetically at every level — useful for diffing two payloads.
