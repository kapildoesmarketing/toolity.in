Cookie Policy

Exactly what Toolity stores in your browser, why, and how to remove it.

Summary

Toolity sets anonymous analytics cookies (Google Analytics, loaded through Google Tag Manager) and uses your browser's local storage to remember preferences. We do not set advertising cookies, and the content you process in a tool is never stored in a cookie or sent to us.

Analytics cookies

These help us understand which tools are used, on what kind of device and from which country, so we know what to improve and build next.

  • _ga — distinguishes anonymous visitors. Set by Google Analytics; expires after 2 years.
  • _ga_<ID> — keeps the state of a visit (session). Set by Google Analytics; expires after 2 years.

Learn more in Google's cookie policy.

Local storage (not cookies)

Some tools save settings or progress on your device using localStorage. This data never leaves your browser.

  • toolity_theme — your light or dark mode choice.
  • Tool settings and drafts — for example the Online Notepad and JSON Visualizer save your text and options so they are there when you return.
  • Game progress and best scores — for example 2048, Snake, Tetris, Flappy Bird, Pong and Tic-Tac-Toe.
  • Timer and widget state — for example the Pomodoro timer and embeddable timers.

Advertising

Toolity does not run ads, so no advertising cookies are set. If that ever changes, this page will be updated before any ads go live.

How to control cookies

  • Block or delete cookies and site data in your browser settings — every tool keeps working without them.
  • Use a content blocker, or install the Google Analytics opt-out add-on.
  • Clearing site data for toolity.in also removes saved tool settings and game scores.
