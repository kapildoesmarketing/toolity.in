How It Works

How to Use CSV Viewer & Editor in 3 Steps

1

Open your CSV

Drop a .csv or .tsv file, use Open file, or paste the text. The delimiter (comma, semicolon, tab or pipe) is detected automatically.

2

Sort, filter and edit

Click a column header to sort, type in the filter box to narrow rows, click any cell to edit it. Add rows, delete rows with ×, or remove exact duplicates in one click.

3

Export

Download what you see — current sort and filter — as CSV, JSON or a real Excel .xlsx file, or copy it as CSV.

FAQ

CSV Viewer & Editor — Frequently Asked Questions

How large a file can it open?

Files up to 50 MB load; the table shows 500 rows per page so the browser stays fast. Sorting, filtering and export always cover every row, not just the page you are on.

Are my edits saved to the file?

Edits update the CSV source box straight away, so Copy and Download include them. Nothing is saved on a server — download before you close the tab.

What exactly does the export contain?

The rows you can currently see, across all pages: the filter and sort order are applied. Clear the filter to export everything.

Is the Excel file a real .xlsx?

Yes — a genuine Office Open XML workbook built in your browser with JSZip (loaded only when you choose Excel). Numbers are stored as numbers, everything else as text; there are no formulas or formatting.

How are quotes and line breaks inside cells handled?

Fields follow RFC 4180: values in double quotes can contain the delimiter, line breaks and escaped quotes (""). Exported CSV quotes any field that needs it.

Is my data uploaded anywhere?

No. Parsing and converting happen in JavaScript inside your browser tab. Your text and files are never sent to Toolity or anyone else.
