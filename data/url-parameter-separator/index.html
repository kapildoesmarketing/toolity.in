            FAQ
            
URL Parameter Separator — Frequently Asked Questions

          

          

            

              Is the URL I paste sent anywhere?
              
No. Parsing uses the browser's built-in URL API and happens entirely on your device. The only network request this page can make is when you click the ? button, which opens a Google search in a new tab.

            

            

              Which tracking parameters does Strip Tracking remove?
              
All utm_* keys plus common click identifiers such as fbclid, gclid, gbraid, wbraid, msclkid, ttclid, twclid, igshid, mc_cid, mc_eid, yclid, _ga and _gl. Anything else stays enabled so functional parameters are never lost.

            

            

              Will the cleaned link still work?
              
Tracking parameters are only used for analytics, so removing them does not change the page you land on. If a site breaks, re-enable parameters one at a time to find the one it actually needs.

            

            

              What does the ? button next to a parameter do?
              
It opens a Google search for that parameter name together with the site's domain, so you can quickly find out what an unfamiliar key like spm or ref_src means.

            

            

              Can I export the parameters as JSON?
              
Yes. Switch the output pane to JSON or Key-Value to get just the active parameters in a structured format, then Copy.
